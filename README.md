# 📷 Live Camera Feed with Python + OpenCV

This project demonstrates how to use **OpenCV (cv2)** in Python to access your computer's webcam, display the video feed in real-time, and exit gracefully.

---

## 🚀 Features
- Open and stream live video from your **default camera**.
- Display the video in a dedicated window.
- Quit the application by pressing **Q**.
- Error handling for cases when the camera is not detected.

---
